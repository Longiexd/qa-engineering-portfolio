# QA-02 — Monthly collected values do not reconcile

**State:** Historical finding; current fix status not verified
**Environment:** Authenticated staging
**Observed:** 28 October 2026
**Evidence:** E01; original screenshot retained privately
**Classification:** Functional defect; P2


Reproduction: Analytics, year 2026, All vehicles. The collected card shows a nonzero aggregate TND, while all twelve monthly Collected cells show 0 TND. With Renault/Clio/QA-VEHICLE-A selected, collected is 1,180 TND, while all monthly Collected cells still show zero.

Impact: the monthly collection breakdown is misleading despite a nonzero aggregate.

Source corroboration: `backend/app/routes/analytics.py:109` initializes monthly `collected`, but the invoice loop at lines 718–747 only updates aggregate collected. Define the invoice/payment month basis explicitly, populate the monthly values consistently, and test that the monthly sum reconciles with the aggregate for the selected period.

Evidence: `analytics-full-page.png` contains both the total and complete monthly table.
