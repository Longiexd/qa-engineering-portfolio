## Preconditions

Authorized staging session; disposable test records; record the deployed build and test account role. The original live UI did not expose an independently verified deployed SHA.

## Procedure

1. Set a desktop viewport of 1280 × 720 and sign into staging.
2. Open Analytics, inspect header/logo, filters and summary cards.
3. Scroll vertically and compare document scrollWidth with clientWidth; restore viewport afterward.

## Expected result

The logo loads, main controls are readable and Analytics has no document-level horizontal overflow. This is the inspected viewport, not proof of every desktop size.

## Recorded observation

Logo loaded; no analytics page-level horizontal overflow
