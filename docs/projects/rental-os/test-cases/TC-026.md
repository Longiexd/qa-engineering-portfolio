Authorized staging session; disposable test records; record the deployed build and test account role. The original live UI did not expose an independently verified deployed SHA.

## Procedure

1. Open a historical test rental whose deposit is explicitly flagged as booked to a legacy account.
2. Expand its deposit settlement/refund controls.
3. Inspect the warning and attempt the refund action only if an authorized disposable fixture is available.

## Expected result

The legacy classification blocks automatic refund and explains why; it does not create a refund or change the held balance. Never bypass this guard to complete the test.
