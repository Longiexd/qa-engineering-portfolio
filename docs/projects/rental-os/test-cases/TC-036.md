## Preconditions

Authorized staging session; disposable test records; record the deployed build and test account role. The original live UI did not expose an independently verified deployed SHA.

## Procedure

1. Session: log out, revisit a protected detail URL, then repeat with an expired disposable session; verify access denial and clear reauthentication.
2. Offline recovery: open an editable synthetic draft, disconnect the browser network, attempt Save, reconnect and inspect saved history before retrying.
3. Rapid actions: in an isolated disposable payment harness invoke the same operation twice and compare receipt IDs, totals and history; do not retry an uncertain live receipt blindly.
4. Keyboard: use Tab/Shift+Tab and Enter/Space to traverse login, navigation, booking form and a modal; test Escape, focus return and visible focus. Record each subcheck separately.

## Expected result

Logout/expiry blocks protected data; offline Save gives a recoverable error without claiming persistence; retries create one financial effect; keyboard focus is visible, follows a logical order and returns after modal closure. This is a grouped exploratory charter: report each subcheck individually and do not assign a blanket pass. Historical checks were not completed.
