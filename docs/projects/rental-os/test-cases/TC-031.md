## Preconditions

Authorized staging session; disposable test records; record the deployed build and test account role. The original live UI did not expose an independently verified deployed SHA.

## Procedure

1. Set the browser viewport to 390 × 844 CSS pixels and sign into staging.
2. Open Calendar and Fleet Care; expand navigation, a calendar entry and one vehicle checklist.
3. Compare document scrollWidth with clientWidth, then restore the original viewport.

## Expected result

No document-level horizontal overflow (scrollWidth ≤ clientWidth); mobile navigation and main actions remain reachable. An internally scrollable calendar may scroll without moving the whole page. Historical pass covered the inspected layouts only.

## Recorded observation

No document-level horizontal overflow; mobile navigation present
