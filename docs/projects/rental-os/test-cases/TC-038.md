## Preconditions

Authorized staging session; disposable test records; record the deployed build and test account role. The original live UI did not expose an independently verified deployed SHA.

## Procedure

1. Create or identify the labelled synthetic customer QA Portfolio Search and its linked quotation/CRM prospect. Record their IDs.
2. Open global search with Ctrl+K, search the exact customer name, then the booking reference.
3. Select the matching result using Enter and compare the opened detail ID with the fixture; repeat for the linked prospect.

## Expected result

Search finds the intended customer, booking and linked prospect; Enter opens the selected record rather than another match. No matching result from an unauthorized company is exposed; live cross-company enforcement belongs to TC-035.

## Recorded observation

Finds QA booking, customer and leads; Enter opens QA record
