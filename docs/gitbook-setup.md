# Publish with GitBook

This repository is prepared for GitBook Git Sync: `.gitbook.yaml` selects `docs/`; `SUMMARY.md` defines navigation. GitBook has not been connected or published by preparing these files.

1. Open a GitBook space and select Set up Git Sync.
2. Connect GitHub and grant GitBook access to this portfolio repository only.
3. Select `Longiexd/qa-engineering-portfolio`, branch `main`, repository root as the project directory.
4. Choose GitHub as the initial content source. The configuration imports `docs/`.
5. Preview navigation, tables and test case links, then publish when ready.

[Official GitBook import guide](https://gitbook.com/docs/guides/editing-and-publishing-documentation/import-or-migrate-your-content-to-gitbook-with-git-sync)

GitHub remains the version-controlled source. GitBook provides a readable documentation site. No paid plan or GitBook account has been created for this portfolio.
